⚽ Copa do Mundo com Java, Spring Data JPA e PostgreSQL

Projeto desenvolvido para praticar conceitos de Java, Spring Boot, Spring Data JPA, Hibernate e PostgreSQL, utilizando dados relacionados à história da Copa do Mundo.

O sistema realiza consultas e gerenciamento de informações sobre:

🌎 Seleções
🏆 Títulos de Copa do Mundo
⚽ Jogadores
🎯 Artilheiros
📊 Relacionamentos entre entidades com JPA

🚀 Tecnologias utilizadas: 

Java,
Spring Boot,
Spring Data JPA,
Hibernate,
PostgreSQL,
Maven,

📚 Conceitos praticados

    JPA e Hibernate,
    @Entity,
    @Table,
    @Id,
    @GeneratedValue,
    @ManyToOne,
    Consultas JPQL,
    Persistência de dados,
    Spring Data JPA,
    Repositories,
    Derived Queries,
    Custom Queries com @Query,
    Integração com PostgreSQL,
    Banco de Dados,
    Modelagem relacional,
    Relacionamentos entre tabelas,
    Chaves primárias e estrangeiras

▶️ Executando o projeto

Clone o repositório:

git clone https://github.com/caiob-dev/Copa-do-Mundo-com-Java-Postgres-Spring-Data-JPA.git

Entre na pasta:

cd Copa-do-Mundo-com-Java-Postgres-Spring-Data-JPA

Execute:

mvn spring-boot:run
